WORKFLOW

一位客戶從認識到成交，在 Vicauria 裡怎麼走

每一步都對應到工作台裡的一個功能。照這個順序做，客戶的資料、行程、追蹤提醒、合約都會自動串在一起，不用自己另外記。

  1. 1

    列名單：先知道要找誰

    客戶探索 › 名單管理
    • 把人脈依熟悉程度分到三區：A 最熟、可以直接約／B 認識、需要先暖身／C 剛認識、還要培養關係。
    • 直接點格子輸入姓名與備註，離開格子就自動儲存；列不夠用就按 ＋ 新增一列。
    成交心法先把 A 名單寫滿，每週固定從 A 名單挑 3 位約見面。備註欄記下對方最近的人生事件（換工作、結婚、生小孩），約的時候就有自然的開場理由。
  2. 2

    約訪：把見面時間記下來

    行事曆
    • 按 ＋ 新增事件，填標題、日期時間；已經建檔的客戶可以在「連結客戶」選起來。
    • 當天的行程會出現在首頁的「今日行程」，打開工作台第一眼就看得到。
    成交心法邀約時用「幫你做一次財務健檢，看看錢都去哪了、離目標還有多遠」當理由，比直接談商品容易答應得多，也正好銜接下一步的財富地圖。
  3. 3

    面談：用財富地圖帶客戶聊

    客戶探索 › 財富地圖
    • 先把畫面轉給客戶，讓客戶自己閱讀並勾選「個人資料蒐集告知暨同意書」，再按 同意並開始。
    • 問卷分成六關：你的輪廓 → 你的後盾 → 錢都去哪了 → 你的起點 → 財務個性 → 財富願景，最後是總覽。
    • 財富願景選好目標後，可以按目標卡上的 🔗 計算機試算，當場用沙盤推演算給客戶看。
    • 最後按 開始生成報告書 →，報告會自動存進「客戶資料」。
    成交心法把問卷當成聊天的引導，不要變成身家調查。「財務個性」那幾題請客戶自己作答，答完你就知道他怕什麼、在意什麼，後面提案時要強調「安全」還是「成長」就很清楚了。
  4. 4

    交付報告：讓客戶看見自己的財務全貌

    財富地圖 › 報告畫面
    • 報告有兩個版本：客戶版・財富畫像（給客戶）與 顧問版・分析筆記（多了每題答題簡表，給你自己看）。先在上方切換好版本。
    • 按 📄 產出報告（列印／存成 PDF），在列印視窗選「另存為 PDF」，就能傳給客戶。
    • 報告內容包含收支總結、資產負債總結、財務個性、財富願景達成率、30 年後的差距曲線，以及「給你的財務小結」。
    成交心法不要急著在同一次會談就提商品。用「財富願景・達成率」和「可以先顧的幾件事」收尾，約好下一次見面「一起討論怎麼補上這個缺口」——第二次見面的成交率通常高很多。
  5. 5

    建檔追蹤：別讓客戶從手上溜走

    客戶探索 › 客戶資料
    • 剛填完的客戶會顯示「尚未命名」，按 ✎ 編輯狀態／筆記／追蹤日期：取名稱（建議用代號）、設狀態、寫顧問筆記、設「下次追蹤日期」。
    • 設了追蹤日期，行事曆會自動出現「追蹤：客戶名」；到期的客戶會被排到最上面並標紅。
    • 客戶的生日會從財富地圖自動同步，生日當天首頁和行事曆都會提醒你。
    成交心法狀態照實更新：追蹤中 → 提案中 → 已成交／已流失。每週打開客戶資料，先處理紅字「待追蹤」的人，就不會漏掉任何一位熱客戶。生日當天傳一句祝福，是最不刻意的關係經營。
  6. 6

    試算提案：把缺口變成具體數字

    試算工具箱 › 沙盤推演必勝
    • 退休基金可以切換兩種模式：➡️ 正算（照現在的存法，能達成幾 %）與 🎯 反算・以終為始（先定目標，回推現在每月要投入多少）。
    • 反算會列出四條路：A 每月定期投入、B 今天一次到位、C 延後幾年退休、D 什麼都不做的話——讓客戶自己選。
    • 另外還有購屋、教育、遺贈、投資理財四個分頁；有貸款需求的客戶可以用「貸款試算室」算月付金與利差。
    成交心法先用正算讓客戶看到「照現在這樣只做到 60%」，再切到反算給出「每月多投入 X 元就能達標」。答案是客戶自己在四條路裡選的，會比你直接推薦更容易點頭。報酬率敏感度表則可以自然帶到「工具選擇」的討論。
  7. 7

    成交簽約：登錄合約，繳費不漏接

    簽約管理
    • 按 ＋ 新增簽約，選客戶、填項目名稱、簽約金額（美金）、年期、繳費方式、簽約時間與匯款時間。分期的話之後每年會自動排好一期。
    • 14 天內要繳、或已經逾期的款項，會出現在首頁的「待繳提醒」；繳了就按 標記已繳。
    • 記得回到客戶資料，把這位客戶的狀態改成「已成交」。
    成交心法在繳費日前主動提醒客戶，是建立信任最簡單的方式，也讓客戶記得「這個顧問很可靠」，轉介紹就會自己發生。
  8. 8

    定期回訪：用成長報告創造下一次成交

    客戶資料 › 追蹤更新／比對報告
    • 半年到一年後，在客戶卡上按 🔄 追蹤更新，會帶入上次的答案，只要修改有變動的地方，送出後會新增一份報告，舊的不會被蓋掉。
    • 有兩份以上報告時，展開 📋 報告紀錄，選兩份按 開始比對 →，就會產出淨資產、儲蓄率、負債比的前後比較與走勢圖。
    成交心法比對報告讓客戶「看見」自己這一年的進步，是加碼規劃與請客戶轉介紹的最好時機：「你這一年淨資產成長了 X，身邊有沒有朋友也想做一次這樣的健檢？」
  9. ＋

    帶團隊：一起衝，進度一眼看清楚

    團隊・團隊討論・行事曆團隊公告
    • 在團隊頁按 建立我的團隊，把邀請碼給夥伴；夥伴在自己的帳號輸入邀請碼、按 加入團隊 就完成。
    • 「團隊工作量」會用燈號標出需要關心的夥伴（🔴 超過 7 天沒動靜、🟡 手上案量偏多、🆕 還沒有客戶），而且只看得到數字，看不到夥伴的客戶內容。
    • 用「團隊討論」發公告、分享心得；重要日子可以在行事曆勾「開放給團隊」變成團隊公告。

客戶探索
🗺️財富地圖顧問式引導問卷，產出客戶的財務健檢報告書▾

怎麼用

  1. 讓客戶閱讀並勾選同意書，按 同意並開始。
  2. 依序填完六關：你的輪廓、你的後盾、錢都去哪了（收入／支出）、你的起點（資產／負債）、財務個性、財富願景。每頁用 下一步 → 前進。
  3. 在總覽頁按 開始生成報告書 →，約 20 秒後報告就會出來。
  4. 用上方按鈕切換「客戶版／顧問版」，再按 📄 產出報告（列印／存成 PDF）。

小技巧

  • 收入、支出、資產每一頁都至少要填一筆；支出填了房貸或信貸月付，負債頁就要填對應的餘額。
  • 金額欄位打字時會自動加千分位，不用自己打逗號。
  • 填到一半切去別的功能再回來，進度還在；但重新整理頁面會清空，填的時候要留意。
  • 報告產生後會自動存進「客戶資料」，出生年月日也會自動變成客戶生日提醒。
  • 想讓封面印出客戶名字：先到客戶資料幫客戶命名，再按「查看最新報告」列印。
📇客戶資料所有客戶與報告、狀態、追蹤提醒、報告比對▾

每張客戶卡可以做的事

  • 查看最新報告 →：開新分頁看報告，也可以從這裡列印。
  • ✎ 編輯狀態／筆記／追蹤日期：客戶名稱、狀態（追蹤中／提案中／已成交／已流失）、下次追蹤日期、顧問筆記，改完自動儲存。
  • 🔄 追蹤更新：重新填一次財富地圖，會帶入上次的答案，送出後新增一份報告。
  • 📋 報告紀錄：看這位客戶的每一份報告；有兩份以上時可以選兩份按 開始比對 →，產出成長比對報告（可列印成 PDF）。

小技巧

  • 上方搜尋框可以用客戶名稱找人；紅字「N 筆待追蹤」代表今天該聯絡的人。
  • 設定追蹤日期後，行事曆會自動出現「追蹤：客戶名」；改日期或清空也會同步。
  • 刪除的客戶會先放進 🗑️ 已刪除，可以還原；按「永久刪除」才會真的消失。
  • 客戶名稱建議用代號，避免留下完整真實姓名。
📝名單管理把人脈分成 A／B／C 三區列名單▾

怎麼用

  • 三區分別是 A（最熟、可以直接約）、B（認識、需要先暖身）、C（剛認識，還要培養關係）。
  • 直接點格子輸入姓名、備註，離開格子就會自動儲存；按 ＋ 新增一列 加列。

小提醒

  • 按列尾的 ✕ 會直接刪除那一列、沒辦法復原，刪之前確認一下。
  • 名單是獨立的，約到面談後，再用財富地圖正式建立客戶資料。
行事曆與團隊
📅行事曆約訪行程、客戶生日、團隊公告▾

怎麼用

  1. 用 ← → 今天 切換月份，點某一天看當天的清單。
  2. 按 ＋ 新增事件：填標題、日期（可以跨好幾天）、時間或勾「全天」，可選擇連結客戶、寫備註。
  3. 要固定重複的行程，勾「設為週期性事件」，設定每幾週一次、重複到哪一天。
  4. 點事件旁的 ✎ 編輯，或刪除。

小技巧

  • 月曆已經標好台灣的國定假日與補假。
  • 客戶生日、客戶資料設定的追蹤日期，都會自動出現在月曆上。
  • 有建立團隊的人，新增事件時可以勾「開放給團隊」，就會變成團隊成員都看得到的公告。
  • 個人行程只有你自己看得到。
👥團隊建立或加入團隊、工作量統計、團隊討論▾

想帶團隊

  1. 按 建立我的團隊，按 ✎ 幫團隊取名字。
  2. 按 複製邀請碼 傳給夥伴。
  3. 夥伴加入後，「團隊工作量」會列出每個人的追蹤中、提案中、已成交、已流失、待追蹤的客戶數量，並用燈號標出需要關心的人。

想加入別人的團隊

  • 在「加入其他顧問的團隊」輸入邀請碼，按 加入團隊。不想待了可以按「退出」。

團隊討論

  • 輸入內容、可以 📷 加照片，按 發佈；每則貼文下面可以留言回覆。

隱私

  • 帶團隊的人只看得到數字，看不到夥伴客戶的姓名、筆記或問卷內容。
簽約管理
📑簽約管理成交合約紀錄與每期繳費提醒▾

怎麼用

  1. 按 ＋ 新增簽約。客戶可以從客戶資料選，或選「＋ 新增客戶（尚未填財富地圖）」直接輸入姓名。
  2. 填項目名稱、簽約金額（美金）、年期、繳費方式（整付／分期）、簽約時間、匯款時間。分期的話之後每年會自動排一期。
  3. 按 展開明細 看每一期，繳了就按 標記已繳。

小提醒

  • 上方會統計逾期未繳、14 天內到期的筆數；首頁的「待繳提醒」也會顯示。
  • 修改年期、繳費方式或日期，會重新排程並清掉已繳標記（會先跳確認）。
試算工具箱
🎯沙盤推演必勝退休、購屋、教育、遺贈、投資理財試算▾

五個分頁

  • 🌤️ 退休基金：輸入年齡、退休後每月生活費、報酬率與通膨、現有資產，也可以把勞保勞退一起算進來。
    • ➡️ 正算：看達成率——照現在的存法，能達成目標幾 %、還有多少缺口。
    • 🎯 反算：以終為始——先定目標，回推現在每月該投入多少，並列出四條路與不同報酬率的對照表。
  • 🏠 購屋基金：購屋能力試算（每月要存多少、頭期款、房貸月付、寬限期安排），以及房地合一稅試算。
  • 🎓 教育基金：子女教育金每月需存多少，含教育通膨。
  • 🗺️ 遺贈方案：遺產稅試算、法定應繼分與自訂分配模擬、最低稅負，輸入後自動計算。
  • 📈 投資理財：本金加定期投入，多少年後累積多少、達成率與實質購買力。

小提醒

  • 試算結果不會存檔。要留給客戶，可以截圖，或用瀏覽器列印。
  • 在財富地圖的財富願景目標卡上按 🔗 計算機試算，會直接開到對應的分頁。
💧收支現金流快速算出年度結餘與儲蓄率▾
  • 在收入、支出表填金額：「月收入」會自動乘 12，「年度一次性」只加一次；可以 ＋ 新增項目。
  • 按 產生結果 →，看年度總收入、總支出、結餘、儲蓄率、圓餅圖與各項比率；可以按 📄 產出報告（列印／存成 PDF）。
  • 這是獨立的快速試算，不會存檔；要完整留存客戶資料，請用財富地圖。
⚖️資產負債表總資產、總負債、淨值、負債比▾
  • 填入四類資產（理財型、投資、不動產、其他）與負債，按 產生結果 →。
  • 看淨值、配置圓餅圖與負債比等比率；負債比超過 50% 會標示提醒。可以列印／存成 PDF。
  • 一樣是獨立試算、不會存檔。

FAQ

常見問題

我的客戶資料，別人看得到嗎？
看不到。財富地圖、客戶資料、行事曆的個人行程、簽約管理、名單，都只有你自己的帳號看得到。就算加入團隊，帶團隊的人也只看得到統計數字，看不到任何客戶的姓名或內容。
報告要怎麼存成 PDF 傳給客戶？
在報告畫面先切換好「客戶版」或「顧問版」，按 📄 產出報告（列印／存成 PDF），在跳出的列印視窗把「目的地」選成「另存為 PDF」，存檔後就能用 LINE 或 Email 傳給客戶。手機上也可以用系統的列印／分享功能存成 PDF。
為什麼報告封面沒有客戶的名字？
剛填完的新客戶還沒有名字。到「客戶資料」按 ✎ 編輯狀態／筆記／追蹤日期 幫客戶命名，再按 查看最新報告 →，從那裡列印就會有名字。
換電腦或用手機登入，資料還在嗎？
在。客戶資料、報告、行事曆、簽約、名單、團隊與訊息都存在雲端，用同一個帳號登入就看得到。只有試算工具箱（沙盤推演、收支現金流、資產負債表、貸款試算室、資金效率健檢）的數字不會存檔，另外字體大小、主題色系這類畫面設定是記在各自的裝置上。
剛新增的客戶，為什麼在行事曆或簽約管理的選單裡找不到？
重新整理一次工作台（瀏覽器的重新整理）就會出現。剛建立或剛加入團隊後，團隊討論也是一樣，重新整理就會更新。
財富地圖填到一半，可以先去做別的事嗎？
可以切到其他功能再回來，填過的內容都還在；但如果按了瀏覽器的重新整理或關掉頁面，填到一半的內容會清空，建議一次填完。
客戶半年後資料變了，要重新填一份嗎？
不用從頭填。到「客戶資料」按 🔄 追蹤更新，會帶入上次的答案，只改有變動的地方就好，送出後會新增一份報告，舊報告保留著，之後可以拿兩份來比對成長。
忘記密碼怎麼辦？
在登入頁點「忘記密碼」，輸入註冊的 Email，到信箱點重設連結就能設定新密碼。登入後也可以在頭像選單的「帳號設定」修改密碼。
臨時忘記怎麼操作，或談 case 卡關怎麼辦？
點畫面角落的「V」泡泡問小V。平台怎麼操作、客戶說要考慮／沒預算／要問家人該怎麼回，直接打字問就好；小V 答不出來的題目，可以一鍵送給開發團隊補進題庫。
遇到問題或有想要的功能？
到左邊選單最下面的「意見箱」寫下來，會在 1 到 2 個工作天內回覆。描述越具體（在哪個功能、做了什麼、看到什麼），越快能處理。
